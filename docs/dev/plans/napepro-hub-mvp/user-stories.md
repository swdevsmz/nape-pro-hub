## ペルソナ

### ペルソナ1: 設定を探す利用者

- 目的: 自分の用途に合う設定を自然文で発見する。
- 技術レベル: 初級〜中級。

### ペルソナ2: 設定を共有する利用者

- 目的: 登録なしで設定を公開し、必要なら後から編集・削除する。
- 技術レベル: 初級〜上級。

### ペルソナ3: 登録クリエイター

- 目的: 投稿履歴、プロフィール、ランキング実績を管理する。
- 技術レベル: 中級〜上級。

### ペルソナ4: モデレーター

- 目的: 荒らし投稿を非公開化し、操作履歴を追跡する。
- 技術レベル: 中級。

## エピック1: 発見と閲覧

### US-001: 登録なしで探す 🔵

**私は** 設定を探す利用者 **として**、登録せずにトップや一覧を見たい。
**そうすることで** すぐにサービス価値を確認できる。

- 関連要件: FR-001, NFR-201
- 優先度: Must Have
- 受入基準: AC-001

### US-002: 自然文で検索する 🔵

**私は** 設定を探す利用者 **として**、「Chromeを左手で操作したい」のように検索したい。
**そうすることで** キー名を知らなくても用途に合う設定を見つけられる。

- 関連要件: FR-004, FR-005
- 優先度: Must Have
- 受入基準: AC-002, AC-006

## エピック2: 公開と管理

### US-003: JSON設定を公開する 🔵

**私は** 設定を共有する利用者 **として**、JSONとキャッチコピーだけで設定を公開したい。
**そうすることで** 大量の項目を手入力せず共有できる。

- 関連要件: FR-002, FR-003, FR-101〜FR-104, FR-202
- 優先度: Must Have
- 受入基準: AC-003〜AC-005, AC-010

### US-004: 設定にいいねする 🔵

**私は** 閲覧者 **として**、ログインせずに気に入った設定へいいねしたい。
**そうすることで** 他の利用者へ価値を伝えられる。

- 関連要件: FR-006, FR-106
- 優先度: Must Have
- 受入基準: AC-007, AC-012

### US-005: 人気を比較する 🔵

**私は** 設定を探す利用者 **として**、期間別人気設定と人気投稿者を見たい。
**そうすることで** まず試す設定を選べる。

- 関連要件: FR-007
- 優先度: Must Have
- 受入基準: AC-008

## エピック3: 登録と運用

### US-006: Googleで投稿を管理する 🔵

**私は** 登録クリエイター **として**、Googleでログインし、自分の投稿とプロフィールを管理したい。
**そうすることで** 複数端末から継続運用できる。

- 関連要件: FR-008
- 優先度: Must Have
- 受入基準: AC-009

### US-007: 不正投稿を制御する 🟡

**私は** モデレーター **として**、投稿を確認し非公開化・再公開したい。
**そうすることで** 公開品質を維持できる。

- 関連要件: FR-105, FR-106, FR-201, FR-401
- 優先度: Must Have
- 受入基準: AC-011, AC-012

### US-008: 検索エンジンから流入する 🟡

**私は** 初回訪問者 **として**、検索エンジンから個別設定ページへ到達したい。
**そうすることで** サービスを知らなくても設定を発見できる。

- 関連要件: FR-301
- 優先度: Should Have
- 受入基準: AC-013

## ユーザージャーニー

### 匿名発見・評価

`トップ → 自然文検索 → 詳細 → いいね`（US-001 → US-002 → US-004）

### 匿名公開

`公開画面 → JSON検証 → キャッチコピー入力 → 索引完了 → 詳細表示`（US-003）

### 登録運用

`Googleログイン → マイ投稿 → 編集/削除 → プロフィール`（US-006）
