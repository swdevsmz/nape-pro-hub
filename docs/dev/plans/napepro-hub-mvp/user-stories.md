# napepro-hub-mvp ユーザーストーリー

## ペルソナ

### ペルソナ1: 他人の設定を見たいNape Proユーザー

- 他の人がどのボタンに何を割り当てているか知りたい
- JSONやキーコードではなく、デバイス図で直感的に見たい

### ペルソナ2: 自分の設定を共有したいNape Proユーザー

- 手入力せず、自分の実機から設定を読み取って公開したい
- アカウント登録はしたくない

### ペルソナ3: 自分に合う設定例を探したいユーザー

- 「Chrome」「縦置き」「コーディング」などの語で設定を探したい

## US-001: 公開設定をカード一覧で見る

**私は** Nape Proユーザー **として**、他の人が公開した設定をカード一覧で見たい。
**そうすることで** 面白そうな設定をすぐ比較できる。

- 優先度: Must Have
- 関連: FR-001, FR-002
- 受入基準: AC-001

## US-002: Launcherのように設定を視覚的に見る

**私は** Nape Proユーザー **として**、投稿詳細でNape Pro本体図とLayer切替を使ってキー割当を見たい。
**そうすることで** 数値やJSONを読まずに他人の設定を理解できる。

- 優先度: Must Have
- 関連: FR-003, FR-004
- 受入基準: AC-002

## US-003: 自分のNape Proから設定を読み取る

**私は** 設定を共有するユーザー **として**、Nape Proを接続して「設定を読み取る」を押したい。
**そうすることで** 設定項目を手入力せず、そのまま共有準備ができる。

- 優先度: Must Have
- 関連: FR-101〜FR-105, FR-901〜FR-905
- 受入基準: AC-003, AC-004

## US-004: 読み取った設定を匿名公開する

**私は** 設定を共有するユーザー **として**、読み取った設定にタイトルだけ付けて公開したい。
**そうすることで** 会員登録せず気軽にファンサイトへ投稿できる。

- 優先度: Must Have
- 関連: FR-201〜FR-205
- 受入基準: AC-005, AC-006

## US-005: キーワードで設定を探す

**私は** 設定を探すユーザー **として**、「Chrome」「左手」「Enter」などで検索したい。
**そうすることで** 自分の用途に近い投稿へすぐ到達できる。

- 優先度: Must Have
- 関連: FR-301〜FR-303
- 受入基準: AC-007

## US-006: 非対応環境でも安全に使う

**私は** 利用者 **として**、ブラウザやFirmwareが未対応なら明確な案内を受けたい。
**そうすることで** 誤動作や設定破損を心配せず利用できる。

- 優先度: Must Have
- 関連: FR-105, NFR-201, NFR-202
- 受入基準: AC-008

## ユーザージャーニー

### 閲覧

`トップ → カード一覧 → 詳細 → Layer切替`

### 公開

`/publish → Nape Pro接続 → 読み取り → プレビュー → タイトル入力 → 公開 → 詳細`

### 検紺

`トップ → キーワード入力 → 絞り込み → 詳細`

## MVP後に回すストーリー

- 他人の設定を自分のNape Proへ適用する
- 設定をForkして自分用に変更する
- Likeする
- 人気順で見る
- アカウントで投稿を管理する
- AI自然文検索を使う
